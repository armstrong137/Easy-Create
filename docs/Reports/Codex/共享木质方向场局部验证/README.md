# 共享木质方向场：局部分叉验证

## 结论

主干和侧枝共用二维连续木质域，接头没有独立图像贴片的横向边界。实际三张图可见木纹随分叉转向。但表面偏刷纹，缺少批准参考中的厚树皮块面、鳞裂和遮蔽层次。本次仅验证局部连接方法，A2 未通过，不构成完整整树候选，不重置已淘汰方案轮次。

## 方法与范围

- 两条变宽曲线的光滑并集决定轮廓，同时混合切向方向。固定种子噪声沿方向场双向卷积，形成连续纹理。
- 材质只烘焙一次；同一规则网格保留固定 UV，通过主干粗度与侧枝长度控制局部形变。不会按年龄重算木纹。
- 这是一块裁切后的分叉，早态也不代表完整幼苗。尚无新枝出生、年轻表皮、根颈、冠层、纸牌和正式页面接入。不可用它证明真实整树成长或完整验收。
- 36,400 个纹理三角包含透明背景区域，尚未裁剪优化。此脚本为独立浏览器绘制实验，未形成手机性能结论。

## 实际证据

`局部早态.png`、`局部中态.png`、`局部成熟态.png` 为 Chrome 实渲，`局部形变.webm` 为同一页面从 0 到 1 的 41 帧、8 fps 采集。

`result.json` 记录实际绘制时的数值与朝向检查：41 个采样姿态均无非有限值或翻面，最小有向二倍面积约 1.616 平方像素。这是离散采样结果，不是所有连续时刻的数学证明。固定 UV 和单次烘焙可在脚本中直接核对；尚无与网格特征点逐帧跟踪的独立附着测试。

