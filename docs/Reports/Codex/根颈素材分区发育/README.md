# 根颈素材分区发育

根颈素材按七条横向控制线分区展宽，上缘横向接点固定。三个浏览器姿态均保留根间空隙，逐行检查未出现分区翻转。接干处木纹尺度突变，幼苗仍带粗根形态。A2 未通过。见 docs/Reports/Codex/根颈素材分区发育。

运行 node tools/tree_scene/scripts/probe-root-collar-asset.mjs 复现。上方短干用于观察接头，不代表整树。

## 接干复拍

根颈短干改为从接合行向上等比例采样，幼龄根颈缩小并保留根间空隙。三姿态复拍中横向接缝减弱，短干仍可辨镜像重复，幼龄根仍继承成熟纹理。A2 未通过。见 docs/Reports/Codex/根颈素材分区发育。
