# 手工构图发育预演

使用 Chrome 实际绘制构图源的十五个部位。每个部位拥有单独的生长时序，沿上游部位的接点移动。受光条纹随对应木体一起移动，枝牌以托枝末端为锚点。全景相机固定，四图与 101 帧短片供检查遮挡和构图。

幼苗具备根、干和叶，成年枝牌周边留白仍在。部位目前只做锚点相随和局部缩放，木体交界仍是可见叠线，叶片和树皮质感未建立。下一步用有独立幼苗及成熟轮廓的连续网格替换局部缩放，并验证牌底与承托枝共享边。此构图预演不计完整 A2 轮次。

从仓库根目录运行 node tools/tree_scene/scripts/capture-authored-growth.mjs 复现。
