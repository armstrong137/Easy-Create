## 额外问题清单

### P0：运行端疑似没有吃到最新透明素材或存在 Web 缓存

现象：视频中树木区域仍显示一块偏粉/偏米色的竖向矩形底，边界从树顶上方延伸到土堆下方。当前仓库里的 `assets/textures/tree_frames/magic_tree_f*.png` 已经是透明 PNG，抽检 f01~f05 四角 alpha 均为 0，且无半透明像素。

判断：如果视频是最新运行结果，那么问题不只在素材本身，还可能是 Flutter Web 资源缓存、浏览器缓存、旧服务进程、或构建产物没有更新。继续改素材前必须先确认运行端实际加载的是 `f4333e4` 之后的 PNG。

涉及位置：

- `lib/presentation/outline/magic_tree_model.dart:54`：树帧资源路径
- `lib/presentation/outline/outline_page.dart:1094`：`Image.asset(... cacheWidth: cacheWidth)`

### P1：首页进入大纲页的转场割裂

现象：0.3s~0.5s 之间，黑色星空首页被一整块浅色页面从右侧硬切进来；魔毯卷轴、树木、页面背景几乎同时出现，没有共享元素或镜头连续性。用户感受会像“从一个 App 跳到另一个 App”，而不是从星球进入同一本书的内部世界。

根因方向：当前导航是普通页面入场，首页星球、右上卷轴、大纲树没有统一的场景过渡。即使树动画修好，入口仍会显得廉价。

### P1：右上折叠卷轴被屏幕边缘裁切，物件感不完整

现象：进入大纲页后，右上角折叠卷轴只露出一段，右侧经常被切掉。它不像“贴边收纳”，更像图片被 viewport 截断。

涉及位置：

- `lib/core/carpet_constants.dart:8`：折叠卷轴宽度 `138`
- `lib/presentation/outline/magic_carpet.dart:539`：贴边态 `AnimatedSlide(offset: Offset(0.62, 0))`
- `lib/presentation/outline/magic_carpet.dart:520`：收起态右上对齐

### P1：枝丫、标签、树干不是一个空间体系

现象：标签胶囊是平面 UI 卡片，卷须是另一套照片/贴图，树干又是第三套图。三者没有共同光照、透视、阴影和遮挡关系。5.5s~6.5s 尤其明显：标签像贴在屏幕左侧，卷须像浮在树前，树干只是背景。

根因方向：

- 标签布局只按 `vine.tip` 的 2D 坐标放置，缺少沿树干深度、贴附点、投影和遮挡。
- 卷须用裁剪显露，但它本身仍是固定精灵贴图，不能和树干纹理真正融合。

涉及位置：

- `lib/presentation/outline/label_layout.dart:75`：`placeMagicLabels`
- `lib/presentation/outline/outline_page.dart:515`：卷须绘制
- `lib/presentation/outline/outline_page.dart:705`：标签胶囊绘制

### P2：早期树木生长反馈弱，用户容易感到“等一下才突然出现枝”

现象：0.5s~2.5s 之间树几乎没有可感知变化；后续新增时，如果树帧变化幅度小，用户实际看到的是“页面静止一段时间，然后标签/枝丫出现”。这会放大“枝丫先动”的错觉，即使时序修正后也可能觉得不自然。

根因方向：

- 当前策略是先让树帧换完，再放枝丫。
- 但早期树帧差异不够戏剧化，树的“生长事件”视觉权重低于枝丫和标签。
- 需要给树干本体增加可见的生长强调，例如嫩芽发光、根部能量、树尖微动，而不是只换静态帧。

### P2：新枝根部连接不够真实，部分枝像从树旁边伸出

现象：章枝向左伸出时，枝根与树干接触处缺少压入、遮挡、阴影和缠绕关系。尤其在土堆附近的新枝，卷须根部容易显得贴在土堆/树前方。

根因方向：

- 章枝根点通过树干半宽估算得到，最终仍是把固定 tendril 图片放在根点附近。
- 没有“树干前后层”或局部遮罩，因此看不到枝从藤条缝里长出来。

涉及位置：

- `lib/presentation/outline/magic_tree_model.dart:776`：窗口模式章枝根点
- `lib/presentation/outline/magic_tree_model.dart:780`：章枝 spriteRect

### P2：标签出现方式仍是 UI fade，不像“从枝端长出/书写出来”

现象：标签胶囊成品直接出现/淡入，缺少跟卷须末端绑定的生成过程。它是功能上可读的，但不符合当前“极致 3D/动画效果”的目标。

根因方向：

- `_labelOpacity` 只做后半段透明度变化。
- 标签没有缩放、沿枝端展开、墨迹书写、或跟随枝端微动的过程。

涉及位置：

- `lib/presentation/outline/outline_page.dart:503`：`_labelOpacity`
- `lib/presentation/outline/outline_page.dart:705`：`_labelCapsule`

### P3：顶部信息层风格断裂

现象：顶部左箭头、中心标题“1”、右上卷轴在同一行，但视觉语言不统一：左箭头是系统图标，标题是普通文本，卷轴是高细节资产。页面主视觉越写实，这种普通系统 UI 越显得跳。

影响：不是功能 bug，但会拉低整体完成度。

涉及位置：

- `lib/presentation/outline/outline_page.dart` 的 `_header`
- `lib/presentation/outline/magic_carpet.dart` 的顶部卷轴入口

## 建议修复顺序

1. 先核实运行端是否加载最新透明 PNG，排除 Web 缓存/旧构建问题。
2. 再彻底修“枝丫先动”：用视频同款晚到流测试覆盖旧枝、旧标签、新枝、新标签四类对象。
3. 修右上卷轴裁切，让折叠态像“收纳在边栏”而不是图片被切。
4. 重做枝丫与树干的空间融合：根部遮挡、阴影、局部缠绕、标签从枝端生成。
5. 最后优化首页到大纲页转场，建立星球进入书内世界的连续镜头。
