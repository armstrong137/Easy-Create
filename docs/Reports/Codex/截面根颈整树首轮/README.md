# 截面根颈整树首轮

截面根颈接入整树预览并完成幼苗、中龄、成熟、枝牌近景及 41 帧短片。根间主开口可辨，根颈向上接回主干。对照批准参考，侧根仍薄，冠腹不足，牌框层次简单。首轮视觉未通过，剩一次整套复审。见 docs/Reports/Codex/截面根颈整树首轮。

运行 node tools/tree_scene/scripts/probe-depth-collar.mjs --section-roots 复现。根区限制取样步长，修正早期的根缘条纹。此候选沿用前版上段及冠簇以单独比较根颈，独立预览仍为离线采集。
