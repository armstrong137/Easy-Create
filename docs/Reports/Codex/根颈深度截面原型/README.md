# 根颈深度截面原型

根颈深度原型使用截面环和逐像素深度比较，在同一相机、同一光向下实渲两种生长姿态。前后根遮挡及截面明暗可辨。当前为相交管体，接头仍有折面，木纹、真实枝牌与共享边待验证，A2 未通过。见 docs/Reports/Codex/根颈深度截面原型。

运行 node tools/tree_scene/scripts/probe-depth-collar.mjs 复现。深度仅用于独立样件的二维投影。

## 同相机着色复拍

根颈深度原型按截面顶点径向法线插值，同相机复拍两姿态。管面明暗不再逐面跳变，管体相交处仍有边界，说明后续需要处理接合几何。A2 未通过。见 docs/Reports/Codex/根颈深度截面原型。
