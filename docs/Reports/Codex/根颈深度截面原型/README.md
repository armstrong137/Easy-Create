# 根颈深度截面原型

根颈深度原型使用截面环和逐像素深度比较，在同一相机、同一光向下实渲两种生长姿态。前后根遮挡及截面明暗可辨。当前为相交管体，接头仍有折面，木纹、真实枝牌与共享边待验证，A2 未通过。见 docs/Reports/Codex/根颈深度截面原型。

运行 node tools/tree_scene/scripts/probe-depth-collar.mjs 复现。深度仅用于独立样件的二维投影。

## 同相机着色复拍

根颈深度原型按截面顶点径向法线插值，同相机复拍两姿态。管面明暗不再逐面跳变，管体相交处仍有边界，说明后续需要处理接合几何。A2 未通过。见 docs/Reports/Codex/根颈深度截面原型。

[平滑着色实图](平滑着色.png)

## 融合表面复拍

根颈深度原型改为各根枝距离场融合，并从同一连续表面计算法线。固定相机复拍两种生长姿态，枝干接缝显著减弱，根间凹槽变浅，根尖仍偏薄。当前无木纹、冠层和枝牌，A2 未通过。见 docs/Reports/Codex/根颈深度截面原型。

[融合表面实图](融合表面.png)。运行 node tools/tree_scene/scripts/probe-depth-collar.mjs 可复现当前版。

## 融合表面木纹

融合根干表面加入按法线加权的三向木纹，固定相机复拍两姿态。接头没有独立贴图边界，纹理整体偏细，根间凹槽仍浅，冠层和枝牌待接入。A2 未通过。见 docs/Reports/Codex/根颈深度截面原型。

[复拍实图](融合表面木纹.png)

## 融合承托枝牌

融合表面原型的木框从承托枝截面定位并并入距离场。浏览器两姿态对照中，中龄无牌，成熟牌底贴合且纸面可读。当前仅为两姿态，文字为二维叠绘，尚未验证连续生长、冠层或命中，A2 未通过。见 docs/Reports/Codex/根颈深度截面原型。

[实图](融合承托枝牌.png)

## 木牌形成

融合木牌由承托枝截面连续长出，纸面随后从底部显露。固定相机采集未长牌、纸面显露中和成熟三个姿态。文字在纸面完全显露后绘制，连续短片和完整冠层待验证，A2 未通过。见 docs/Reports/Codex/根颈深度截面原型。

[三姿态实图](木牌形成三姿态.png)

## 冠层三姿态

融合表面增加四条冠枝及六组枝端叶簇，空书、半龄、成熟三姿态完成浏览器实渲。枝牌留白保留，成熟冠层仍显分散，根间凹槽偏浅。冠簇当前按枝端投影叠绘，连续短片与枝牌独立近景待补，A2 未通过。见 docs/Reports/Codex/根颈深度截面原型。
