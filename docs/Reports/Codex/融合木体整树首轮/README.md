# 融合木体整树首轮

融合木体整树首轮完成固定相机的幼苗、中龄、成熟、枝牌近景和 41 帧连续短片。融合托枝近景承托明确，牌面可读。对照批准参考，冠层仍是分立枝端小团，根间凹槽偏浅，木纹尺度和框面仍较单一。首轮视觉未通过，剩一次整套复审。见 docs/Reports/Codex/融合木体整树首轮。

第二轮复查冠腹是否闭合而保有间隙、根部凹槽是否加深且不变成尖片、枝牌是否保持可读并融入木质。复现运行 node tools/tree_scene/scripts/probe-depth-collar.mjs。短片逐帧离线渲染，8 fps 是编码帧率。
