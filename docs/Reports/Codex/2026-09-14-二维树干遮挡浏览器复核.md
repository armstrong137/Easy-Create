# 二维树干遮挡浏览器复核

## 结论与范围

本轮是正式二维页面的局部改进，整体视觉目标仍未完成。没有调用额外收费图像服务，没有修改原始树图或既有实验三维资产。

改前四个枝基像木疙瘩贴在主干表面。现在将原图主干按同源坐标重画到枝牌前方，遮住伸入主干内部的枝基；外侧枝条、牌面继续显示。四枝和成年阶段的贴片鼓包明显减少，但接入口的纹理方向仍有差别，不宣称已经与主干完全一体。

## 实现

- `illustrated_tree_trunk.dart`：原始 941×1672 坐标下的分阶段主干内轮廓，按照底图相同的 cover/contain、bottomCenter 映射，禁止羽化、抹色、拉伸新素材。前景忽略点击和重复语义。
- `outline_page.dart`：底图 → 章/节枝牌 → 主干前景 → 共用生长光效。仍保持同一视口。
- `tree_standin.dart`：独立使用时默认保留光效，组合场景关闭底图内光效，只在最上层绘制一次。

像素检查曾检出边缘双重发光（最大通道差 4）；已改为单一顶层光效，不通过放宽阈值掩盖问题。最终带光效的原树/合成树比较允许最大差 1，检查通过。

## 未完成与下一步

1. 幼树引子的枝牌相对树干仍过大，现有固定尺寸与挂点不匹配。先按幼树真实分叉设计较细的同风格枝条，保持牌面文字可读；不能只整体缩小牌子凑比例。
2. 中后期接入口仍需与主干纹理方向匹配；当前遮挡解决鼓包，并未生成连续树皮。
3. 成年生产素材仍是近景树干，完整树冠、根冠镜头未验收。实验镜头仍保持关闭。
4. 六档换图尚不是真实连续生长，当前裁剪枝条也不等于结构抽生。不能将本轮截图当作成长动画验收。
5. 最终浏览器图仍未达到批准效果图，后续应直接展示真实页面和动画逐段验收，不以机器指标替代视觉判断。
