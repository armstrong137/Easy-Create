## 第二轮整体复审

| 首轮问题 | 本轮修改 | 实际结果 |
|---|---|---|
| 横枝梯架 | 主干曲率增大，主枝上扬，细枝改为分叉层级 | 梯架减弱，但仍像稀疏分叉网，缺乏古树多级承托体积 |
| 幼冠和冠腹 | 细枝成组发叶，保留初生叶，叶群沿当前枝段生长 | 幼苗叶量增多；成熟叶群反而分散，未形成宽冠体块，顶部超出画面 |
| 扁平根裙 | 提高根颈、减小主干底部宽度，拉开根趾，增加接地阴影 | 根间负空间可见；根面仍扁，缺少前后遮挡与厚度，幼苗阴影又偏大且离根 |
| 模糊枝牌 | 近景按镜头坐标重算木质轮廓，加厚框并增加内缘 | 轮廓比全景放大清晰，但源材质分辨率仍不足，木框简单；字可读不代表风格达标 |
| 木体连续性 | 沿用同一源木质域的截面反查 | 中龄出现黑带，反查存在实质绑定错误；方向场连续不等于材质附着正确 |

## 材质空域反查诊断

诊断在当前实体内部（轮廓深度大于 0.5）检查源材质采样透明度是否小于 1/255，不改变填色、不隐藏错误。实际结果：

- 幼态 466 个实体采样落入源透明区，当前木体共覆盖 1,932 像素。
- 中龄 218 个，成熟全景及近景均为 0。
- 41 个成长采样中的最大数量为 478。

这说明旧的有限数值检查远远不够。当前各枝都参与全局 UV 坐标混合，幼龄时相邻芽枝挤在一起，坐标平均可能落到源木体之间的透明空域。采样 RGB 在那里为零，从而形成黑带。下一方案必须约束实际父子关系、源材质实体覆盖和中间年龄附着，不得仅对坐标做有限值检查或用默认木色补洞。

整树仍无固定 UV 网格，`fixedUV=false`、`triangles=0`、`minimumArea=null`。反查域的结果不能继承局部网格朝向通过结论；未验证实际点击、手机性能、历史、规模及长期稳定性。
