# 层叠素材整树首轮

层叠素材整树首轮完成四张实图和 41 帧短片。每个采集姿态检查 72 个侧枝纹理三角形的朝向与面积。对照批准参考，根颈有体积但主干过细长，裸枝较多，接合木纹拉伸且有细缝，枝牌木框为简单方框。首轮视觉未通过，剩一次整套复审。见 docs/Reports/Codex/层叠素材整树首轮。

运行 node tools/tree_scene/scripts/probe-root-collar-asset.mjs --assembly --capture 复现。图像为实际 Canvas 渲染，短片 8 fps 编码不代表运行帧率。根颈仍由分区图像映射，侧枝与主干几何尚未共边。第二轮必须同时处理冠层比例、承托枝粗度、木纹过渡及框体层次。
