# 共享图集根颈接合：局部验证

## 实图判断

左根、右根和前根已接入现有两级枝架，根颈至主干的木纹连续，根间两处负空间可辨。已查看局部三姿态和根颈近景：侧根仍像薄片，前后根的遮挡和接地体积明显不足，前根偏小。该视觉差距未解决，不能以技术检查通过认定根颈完成。

本次尚无冠层、枝牌或完整幼苗，不是新完整 A2 候选。十六套完整方案两轮淘汰状态不变，A2 未通过，正式页面未接入。下一步应将当前木体放进完整冠层与承托枝牌构图，统一列出整体差距，避免继续只调根尖或枝尖。

## 真实几何和材质归属

生成器读取已提交的两级分叉输入，保持其原有姿态。左根复用主干左缘四段，右根复用右缘四段，前根复用下缘四段；每段二分，三个接入口各有九个实际共享顶点，共增加十二个母体顶点。根身和圆趾分别生成，按年龄独立控制膝部、展幅和末端，不缩放成年整树。

最终 1704 顶点、3004 三角。主干、一级枝、二级枝、左根、右根、前根六个归属域，五处实际父子接合共 40 条共享边。固定 UV 使用同一 1200×1440 不透明图集，真实木体轮廓与根间空隙由网格负责。三个接触阴影跟随当前根趾与末端截面，不使用固定大小的幼苗阴影。

新材质 `rooted_bark_field_v1.png` 通过 imagegen 技能和内置工具生成，源稿与完整提示词已入库，未使用 CLI 后备路径。它仍是材质域，不能作为成年整树图片用于缩放成长。

## 检查和保留的失败记录

首版将转向、收窄和圆趾鼓起放在同一条带上，三个区间分别有 26、33、34 个不安全三角，见 `initial-rejected-intervals.json`。没有放宽检查阈值；修正截面转向，并将圆趾作为末截面之后的独立单元，避免参数线折返。

最终检查：

- 实际图集 1,728,000 像素全不透明，1704 个 UV 均在界内，3004 面与原生二进制一致且 UV 非退化。
- 实际边邻接匹配六个域的父子关系及 40 条接边，开放木面完整连通，无非流形边或共享面方向错误。
- 将左根父域改到二级枝、同时破坏原生面与图集面中的真实根边、将图集像素改透明，三个反例均拒绝，见 `negative-controls.json`。
- 0–0.18、0.18–0.5、0.5–1 三个完整顶点插值区间的面积二次式及原 Float32 舍入界通过，最小余量约 `3.294×10⁻⁸`。仅覆盖所记录的 X-Z 正交投影和线性姿态插值，不证明其他镜头、GPU 像素或真实手机性能。
- 41 帧实渲未翻面，8 fps 为编码帧率。Chrome 实际解码时长 5.125 秒并查看 2.5 秒中段，见 `video-review.json` 与 `视频中段.png`。
- 单分叉与两级分叉入口的八张 PNG 重新渲染后，SHA256 与原归档一致。

上述检查不证明参考风格、根部体积或整树成长自然。特别是当前只有一个开放前表面，不能把几何 Y 深度和法线明暗当作已验证的前后遮挡。
