# 本地 Blender 原生渲染核验

## 出图通路

从头调用内置出图工具请求2048×4096，实际输出887×1774且偏离羊皮纸背景，未接入。此后改为本机模型渲染，没有调用图像API/CLI付费后端。

从官方 `https://download.blender.org/release/Blender4.5/` 下载便携版4.5.9，存于build/local-render-tools，没有系统安装。

压缩包SHA-256与官方清单一致：`41da973b9bf95bb312cbeff4d1982feb13259b43c821686b9bafea4dfe5477cf`。

## 实测

使用工作区现有 magic_tree_master.blend 和 render_magic_tree_art_previews.py 的辅助函数，仅修改内存中的渲染配置，不保存模型。EEVEE 64采样，1536×2730，透明RGBA，原生渲染约28秒，退出0。

输出留存：`picture/魔树动画素材/本地渲染核验/mature-native-probe.png`。

PNG文件头：1536×2730，colorType=6，4026001字节。是真实模型渲染结果，不是旧图放大。

渲染器提示源文件由更新版本写入，存在兼容风险；未覆盖源文件。现有模型与预览脚本包含历史未提交工作，此证据仅对应当前工作区，不声称干净克隆可复现。

## 视觉否决

目视根部与树干材质明显不一致、主干有疑似重叠几何、冠部构图裁切，叶簇缺乏批准图的质感。**不能投入生产。** 高分辨率并不意味着美术达标。

对象读取结果：TrunkSkinned有43137顶点和BarkOldPBR/BarkOldPBR.001两个材质；Roots有1452顶点、BarkOldPBR.001；CrownGuide有7800顶点；LeafPrototype只有4顶点、LeafBroadPBR.001。预览脚本另外按叶簇锚点重建叶片。

这些结果将下一步定位到模型/材质配合与取景，而不是继续向低分辨率图像请求“更高清”。本地高分辨率渲染和透明输出已可用，但生长动画、枝干衔接、最终视觉一致性仍未完成。
