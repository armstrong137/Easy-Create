# 本地透明枝条样件复核

上轮证据确认内置出图的两张细枝候选均没有 alpha。本轮改用已有 three.js、Chrome 软件 WebGL 和树皮材质渲染独立枝条几何，没有调用图像 API、收费服务或抠图处理。

新增 `tools/tree_scene/scripts/render-branch-study.mjs`，执行：

```powershell
node tools/tree_scene/scripts/render-branch-study.mjs picture/魔树动画素材/枝牌候选/2026-09-14-本地几何枝条
```

输出透明 `branch.png`、米白底 `preview.png` 和 `report.json`。尺寸 1536×1024；透明占比约 94.277%，完全不透明约 5.548%，页面脚本错误为零。脚本检查透明与可见像素同时存在，异常时退出失败；这不代表视觉通过。

已看米白底实际渲染：背景接合干净，但锥管轮廓过于规则，分叉为简单穿插，树皮虽有贴图和凹凸光照，缺少参考图中块状树皮的几何起伏和分叉根颈。右端是开放连接端，单独看为直切口，生产接合时不能裸露。当前明确不接入。

这次验证了可控本地输出真实透明素材的路径。后续应改为连续分叉曲面、自然根颈和有厚度的树皮，再加入牌框、嫩叶；暂不以叶片遮盖目前形体问题。没有修改正式二维或实验三维场景，整体目标未完成。
