# 连通网格整树首轮审查

本轮完成新连通网格路线的第一套整树样件：幼苗、中龄、成熟、枝牌近景及连续成长短片。结论是**视觉拒绝，A2未通过**。不接入正式应用，不进入千章回归。此前两轮被淘汰的平面轮廓路线保持淘汰；本轮是新连通网格路线的首次完整审查，不将局部技术验证计作额外美术轮次。

## 实际实现与证据

统一规格whole_tree_spec.py定义主干、七组主枝、根系、枝框、叶挂点和出生规则。volume_proof.py在独立Blender场景中将木质结构做体积并集，固定拓扑、UV和绑定；两个枝框也属于同一连接体。生成后由独立Flutter入口drawVertices实际绘制木质网格，叶片使用局部叶图并绑定当前枝段，纸面和文字在同一投影坐标系中绘制。没有阶段整树换图或成年树整体缩放冒充成长。

木质网格9655顶点、19310三角形，一个连通分量、零非流形边；几何绑定二进制1506180字节，固定2048基色图集2401774字节。成熟有1911片叶、两块牌面；初龄21片叶、零牌，中龄1155片叶、一块牌。这里的数量仅说明实际绘制内容，不能证明形态自然。

生成时19组材质投影曾超过Cycles着色器栈限制，导致黑图集；修复为每批最多六组发光烘焙、线性累加，最终重新生成。旧七组片段会使用两批，未据此宣称旧证据已重跑。Flutter明暗增加近似显示空间校正，但不等于与离线灯光物理一致。叶片与木体按24个深度分段混合，纸面最后绘制，仍非精确深度缓冲。

证据来自build/qa/whole-tree-2d/2026-11-01T12-55-31.118Z，已复制到同目录[连通网格整树首轮/index.html](连通网格整树首轮/index.html)，含四张必需实图、手机全景、growth.webm、result.json与geometry.json。全景相机固定900×1280，近景使用430×932视口。代码与资产SHA256在result.json中。

独立短片由Flutter逐帧计算树龄0至1的101个状态，画面包含树龄及时间；通过支持的JPEG管道编码为10fps WebM，约10.1秒。不含静态等待或转屏切换。编码帧率不是实时绘制帧率。先前PNG编码因内置编码器缺少image2输入支持而失败，失败记录与原始帧保留在build/qa/whole-tree-2d/2026-11-01T12-51-37.034Z，不能当成功证据。

## 整套审查：未通过

| 项目 | 当前结果 | 第二轮必须解决 |
|---|---|---|
| 成熟宽冠 | 主枝逐层横伸，像修剪枝架；重复叶球分散，未形成古树宽冠 | 主枝更低处分叉、向上拱起，冠层形成整体层次与负空间 |
| 空书树苗 | 固定全景下极小，叶片集中在低处，顶端裸尖；不是可信的完整树苗 | 重新协调幼龄干长、粗度、顶芽与展叶，不用放大成年树替代 |
| 根颈 | 结构连通，但向地面摊平，仍有裙边与平切轮廓 | 更高根颈向粗根立体过渡，保持接地和自然遮挡 |
| 树皮与叶片 | 树皮浮雕感不足、混合纹理偏软；单叶反光重复成花球 | 统一低饱和材质和光向，改善粗纹理、叶片方向与疏密 |
| 枝牌 | 木框连接真实，但纸面外露、框纸关系不完整 | 框内纸面随实际四角绑定，轮廓、承托和阅读尺度统一 |
| 构图 | 近景树枝会进入顶部树龄文字区 | 绘图区正确裁剪，手机和宽屏操作区均可读 |
| 成长 | 同一网格形变连续，叶片逐步出现；生态比例仍失败 | 对关键中间状态作整体审查，干、枝、叶增粗展叶协调 |

纸面初版文字重叠已修为正常字号逐字绘制，最终“第九章”“第一节”可读；上述枝牌缺陷指框纸关系，不将已修复的文字错误继续列为当前故障。近景和全景均已查看，不能只看缩小图回避缺陷。
