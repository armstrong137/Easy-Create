# 枝叶材质样件复核

基于已闭合的连续分叉样件，接入现有树皮法线、粗糙度图，以及真实透明叶片图集。叶片使用带弯曲深度的细分面和图集 UV，叶柄摆在枝梢位置，没有对图片做抠图或重采样处理。没有收费服务调用。

复跑：

```powershell
node tools/tree_scene/scripts/render-branch-study.mjs picture/魔树动画素材/枝牌候选/2026-09-14-枝叶材质样件
node --test tools/tree_scene/test/branch-study-surface.test.js
```

渲染输出 1536×1024，真实透明约 92.234%，完全不透明约 7.604%，脚本错误为零。连续曲面检查通过。候选目录包含透明图、米白底预览和数值报告。

已检查米白底实图：叶脉清楚，叶片有光照深度，透明边缘没有棋盘底。枝干形体仍过于规则、根端圆钝，树皮法线只是光照细节，不等于有块状厚度的真实树皮。少量叶片不能使这个基础形体达到批准参考的质量。因此未替换正式素材，也未把离线计算接入手机。

整体目标未完成。下一步应解决枝干自然节点和真实根颈，而不是继续添加叶片或提高法线强度来掩盖形体问题。
