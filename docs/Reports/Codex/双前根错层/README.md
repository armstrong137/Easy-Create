A2 不通过。双前根是已淘汰手工平面枝架上的素材试验终点，停止给该枝架继续加叶或改根尖。下一方法验证有深度截面和遮挡的根颈、主干及承托枝组合，渲染时仍采用二维材质和固定相机。先比较剪影和明暗能否同时表达体积，再扩展为整套成长。原型及证据保留，完整候选轮次不变。
