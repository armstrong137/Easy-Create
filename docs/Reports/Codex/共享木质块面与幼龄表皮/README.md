# 共享木质块面与幼龄表皮

## 实图结论

同一二维分叉增加沿方向场排列的不规则块面、裂隙和细木纹。三张浏览器实图显示：早态表皮较光滑，中态裂隙逐渐显露，成熟态块面较清楚，分叉没有另起贴图的横缝。

对照批准参考 `assets/source/magic_tree/references/章节目枝直接承托效果图.png`，当前材质仍偏规则多边形，缺乏厚树皮的翘边、鳞裂和遮蔽层次。局部效果有变化，但未达到参考质量；A2 未通过。本次不增加完整候选轮次，不续改任何已两轮淘汰的整树。

## 实现边界

- 同一连续域内固定块面种子，使用该处枝干方向拉长块面；表面明暗按块面起伏及统一左上光向计算。没有主干与侧枝的独立 UV 片段。
- 粗糙表皮和光滑表皮在同一次烘焙中由同一方向场产生；年龄只混合同一 UV 位置的表面强度，不重新布置裂纹。光滑幼态是局部材质过渡，不代表已完成完整幼苗。
- 36,400 个三角的局部形变、固定 UV 与上一版本相同，仍包含透明区域。无根颈、冠层、承托枝牌、正式页面和手机性能结论。
- 独立命令增加 `--bark`；无此参数的默认路径三张 PNG 的 SHA256 均与提交 `1298a32` 归档实图一致。
