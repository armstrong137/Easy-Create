# 枝条连续分叉复核

在 3ec332c 的本地透明渲染基础上，将相交锥管替换为距离场并集提取的连续曲面。每条分枝内部不累计膨胀，仅在分枝与主枝的交界平滑根颈。已有树皮基础色用于世界尺度投影，透明背景仍由 WebGL 直接输出。

新增 `BranchStudySurface.js`，仅被离线样件脚本使用，不接入手机实时场景。距离场分辨率 180，其计算和内存开销不应带到手机运行时。

验证命令：

```powershell
node --test tools/tree_scene/test/branch-study-surface.test.js
node tools/tree_scene/scripts/render-branch-study.mjs picture/魔树动画素材/枝牌候选/2026-09-14-连续分叉
```

测试通过：提取顶点邻接图只有一个连通分量，三角形边不存在只被一面使用的裸露边。它证明本样件不再是三根独立管体穿插，不代表所有可能参数都满足流形条件。

渲染为 1536×1024，透明约 93.778%、完全不透明约 6.046%，浏览器脚本错误为零。查看米白底预览，分叉过渡已连续，原有穿插边界消失。树皮仍是缺少真实厚度的贴图质感，枝梢轮廓规则，根端过圆，不符合批准图中的自然木质形态，因此不接入正式页。

输出透明图、预览及报告保存在上述候选目录。下步需要改善树皮几何厚度和自然节点轮廓，再与牌框和树干连接；不能把封闭表面测试当作美术验收。整体目标仍未完成，未使用收费接口。
