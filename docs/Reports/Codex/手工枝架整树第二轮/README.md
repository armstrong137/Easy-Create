# 手工枝架整树第二轮

2026-11-04 手工枝架整树第二轮用有空隙的叶簇替换封闭冠块，并按木体网格绘制收尖光面。四图和 101 帧短片已归档，牌底两条共边仍成立。对照批准参考，树冠仍像数层分离的盘状叶簇，根颈轮廓尖折，受光面硬，木框仍方直。A2 两轮均未通过，淘汰本套平面枝架和程序叶簇的整树造型。见 docs/Reports/Codex/手工枝架整树第二轮。

对照树形正视图，冠间空隙更清楚，但主次枝的承托关系和叶片群落形状仍弱。前根收尖，缺少与根颈连续的圆钝明暗。对照枝牌承托效果图，近景留白和可读性成立，牌框的木质转折仍缺体积。

下一方法先验证高质量局部根颈和冠簇作为独立资产，并保留用于形变的控制点。先通过局部材质对照再扩展完整生长，复用共边审计。复现运行 node tools/tree_scene/scripts/capture-authored-growth.mjs。
