# 定向根脊与根间空腔

新根颈原型使用定向截面根脊与显式根间空腔，在固定相机、同光向下实渲两个姿态。两处空腔可辨，入口仍偏规则，侧根近地段仍薄。尚未接入整树枝冠与枝牌，A2 未通过。见 docs/Reports/Codex/定向根脊与根间空腔。

运行 node tools/tree_scene/scripts/probe-root-sections.mjs 复现。

## 错层空腔

根间两处空腔按深度错开并收窄，加入局部遮蔽。固定相机两姿态实渲中主空腔不再呈对称拱孔，成熟副空腔被前根遮挡，侧根末段仍薄。A2 未通过。见 docs/Reports/Codex/定向根脊与根间空腔。
