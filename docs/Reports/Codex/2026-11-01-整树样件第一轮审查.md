# 整树样件第一轮审查：拒绝集成

本轮是新整改计划A2的第一次整套样件。采用独立Canvas2D曲线/截面方案，复用树皮细节素材，直接绘制枝干、根、叶簇和承托牌；没有替换正式Flutter页面，也未读取小说数据库。该实现只验证造型方案，不能证明Flutter的运行效果、命中或性能。

## 整套审查结论

| 项目 | 对照批准参考的实际结果 | 判定 |
|---|---|---|
| 宽冠与叶簇 | 木骨架仍占主导，叶簇分散，大片空洞没有形成参考的承托层级 | 失败 |
| 截面与材质 | 全局渐变和纵向线条让木质呈黑色带状，缺少局部截面体积；减少碎亮也没有得到自然树皮 | 失败 |
| 根颈与接地 | 根像平切带状条，幼苗根端未到阴影地面，底部平切边暴露 | 失败 |
| 成长 | 曲线按进度延伸，但部分叶簇放在末态位置，在母枝长到之前已出现；连续参数不能证明生态自然 | 失败 |
| 木质枝牌 | 承托枝较扁，牌框类似普通圆角界面，未与树体统一为自然木质结构 | 失败 |
| 原则约束 | 无阶段整树换图、成年树整体缩放；没有改正式页面或用户数据 | 满足约束，但不抵消上述失败 |

不能将本轮称为“视觉改善通过”，也不能进入A3集成或运行正式页面千章回归。第一轮已完整审查，不能拆成若干局部修补并重置轮数。

## 第二轮必须同时解决的事项

1. 以各截面法线计算局部明暗与纹理方向，取消将整条枝干涂成一条全局渐变带的方案；先证明粗干和分叉体积。
2. 根颈从母干基部连续展开，幼苗也必须有实际接地根；树龄改变根幅和粗度不能把整棵树悬在地面之上。
3. 叶片出生取决于母枝是否已到真实锚点，每片叶子有可追溯叶柄；按前后叶簇组织冠层，不再把散叶撒在末态位置。
4. 承托枝与牌框使用同一木质造型语言，统一光向、细节密度和阅读尺度；不以圆角UI框代替自然木牌。

第二轮仍须四图加连续短片同时审查。若整体仍失败，按唯一验收表淘汰该方案并重新评估实现方法，不继续第三轮参数微调。当前目标保持进行中。
