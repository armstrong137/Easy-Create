# 共享边界分枝发育：局部验证

本轮把幼干及首个子枝做成独立原生表皮，验证短芽到伸枝的发育，不再从成年碎枝轮廓压细。实际共享边界、连续姿态和幼干明暗已有证据；表皮风格和接头材质仍未通过美术审查。没有根冠、枝牌或完整树苗，A2未通过，七套完整方案两轮淘汰状态不变。

## 假设、实现与成功范围

假设：幼态碎枝来自始终存在的成年轮廓。保留原绘制和审计工具，改为母干表皮和子枝共用真实边界，由干长、芽长、开口宽度分别控制发育。最小验证要求是幼干没有成年碎枝，短芽沿真实母干伸出，中间帧无脱节/翻面，年轻木质降低纹理后仍能读出截面体积；这不等于完整树形合格。

branch_development_proof.py生成801顶点、1408三角、98748字节的单个开放前表面。母干右侧九个顶点直接成为子枝首排，八段边由两侧面共用，非两个封口互相覆盖。年龄0/.18为短芽、.5/1逐渐伸长增粗；每个姿态的接点都来自同一母干边界。Dart直接插值同一网格和固定UV，短片不播放阶段图片。

母干和子枝分别按枝长展开UV，共点处允许UV分缝。首稿的UV挤压造成大块横纹，分缝后减少；局部边界材质缝仍可辨，旧树皮材质与批准参考的插画风格尚未统一。幼干上下平切是局部截段边界，不是完整树苗的根或枝梢，不把它当整树方案。

[局部实图/短片及对照](局部分枝发育验证/index.html)保存结果，完整网格、母版、原始帧、脚本存电脑迁移包/本地备份/验收记录/2026-11-03-局部分枝发育验证。

## 幼木体积的实际绘制问题

旧绘制先把截面明暗与纹理相乘，再对结果作低对比度过滤。低对比度同时压掉了年轻木质的体积。相同幼干扫描线修正前红通道107至109，修正后58至95，左右明暗得以保留；只说明该扫描线及已查看图中的变化，不用这个数字宣称整体自然。

实验入口新增postTextureLighting，仅由本块不透明原生表皮启用：第一遍用纹理与滤镜，第二遍乘截面明暗。旧资产缺省保持原路径，透明图集不能直接套此开关。接口语义依据[Flutter drawVertices](https://api.flutter.dev/flutter/dart-ui/Canvas/drawVertices.html)及[BlendMode](https://api.flutter.dev/flutter/dart-ui/BlendMode.html)，实际结果另由浏览器扫描线和截图核对。没有修改源PNG或生成树龄贴图。

## 验证结果及界限

- 首稿短芽根部有翻面，原区间审计拒绝；调整起始切线及开口比例后仍用原误差界审计，失败记录initial-fold-rejected.json保留。
- 最终全1408三角在0至.18、.18至.5、.5至1三个完整插值区间通过；扣除Float32误差界的最小余量分别3.83574×10⁻⁷、7.89437×10⁻⁷、9.97962×10⁻⁵。
- audit-branch-development.mjs从实际二进制推导母子共享边、面朝向、连通及UV：八共用边/九共用点，全部801顶点连通，前表面无孔；最小UV双面积304.13纹素²。不是闭合三维实体或无缝材质证明。实际破坏子枝首排边索引的反例被正确拒绝。
- 实际浏览器运行错误0，固定相机101状态/10.1秒，0/.18/.5/1四姿态均执行源顶点对照，共3204样本；静态三姿态最大误差2.35240×10⁻⁷，三姿态均1408正向三角。已查看幼干、中间姿态、成熟局部、接头及.18/.25源帧。
- 同一新Dart构建的旧默认局部模式实际浏览器回归成功，postTextureLighting缺省不启用；分析无问题、独立release构建和三项区间正反例通过。正式lib、web、pubspec和数据未改。
- 2332观测状态的几何CPU p95为.5ms、绘图记录1.4ms，仅本局部浏览器记录，不含GPU完成时间，非整树/真机/千章性能结论。430×932仅手机浏览器视口。
