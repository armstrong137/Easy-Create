# 书名深色树皮可读性验证

## 原因与修改

书名始终以深色绘制，成熟树干位于标题下方时缺少对比。仅在书名字形周围增加1逻辑像素的浅色轮廓，不增加矩形底板、不改变标题布局、不增加重复文本节点。

## 验证

- 新回归测试先失败：原样式 shadows 数量为0；加入轮廓后通过。
- `flutter test test/presentation/outline_page_test.dart --no-pub`：20项通过。
- `flutter build web --no-wasm-dry-run --no-pub`：退出0。
- `node scripts/check-illustrated-outline.mjs http://127.0.0.1:8780/`：退出0，errors为空，创建十章两节，输出五张截图。
- 截图目录：`build/illustrated-outline-check/2026-09-09T02-02-56.761Z/`（UTC时间）。
- 直接查看 `00-empty-430.png` 和 `12-mature-430.png`：浅背景与深树干上的 Visual QA 书名均可辨认；未增加标题底板。

## 范围限制

测试约束轮廓存在和单一文本节点，不能单独证明视觉质量，故另作浏览器目视核对。本次截图使用英文测试书名，不代表所有中文长书名和真机字体均完成验收。

枝根接头、阶段换图、浏览历史章节时的视野移动等仍未修复。整页与批准渲染图的一致性未通过，本次只交付书名可读性修复。
