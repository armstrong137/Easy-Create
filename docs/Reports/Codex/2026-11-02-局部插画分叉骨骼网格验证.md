# 局部插画分叉：真实骨骼网格验证

这是完整控制面路线两轮失败后的新方法评估。局部Y分叉图作为材质，由真实网格和骨骼分别改变主干、侧枝长度、粗度与姿态，**不是整树阶段图，不是完整幼苗或成熟树，不代表A2通过**。

## 当前实际结果

使用imagegen技能及内置image_gen制作左右两格局部Y分叉，保存到assets/source/magic_tree/textures_source/fork_component_source_v1.png。没有根、叶冠或整树。提示词、原始输出、哈希和透明统计见同名.md；本轮只验证左格，右格未验证。

新增illustrated_fork_proof.py，从实际图中的干基、叉心、干顶和侧枝转折位置定义五个骨骼点、四条边，生成48×64格透明材质网格。3185顶点、6144三角形、488724字节，三组骨架姿态使用同一UV和图像连续插值。主干和侧枝使用不同位移及宽度变化，不是把整个构件等比放大。

独立Flutter读取已有poseFrames，新增unlitTexture保留插画中的光照，groundShadow=false关闭构件脚下的假接地影。默认旧材质逻辑保持，正式应用未引用这些字段。初次静态分析提示条件语句缺少花括号，已修正后重新分析、重建和采集，证据对应最终源码。

已查看三个实际状态和近景：树皮大块体积、沿叉流动的纹理与苔痕在Flutter中保留，浅色背景未见明显矩形底或黑边，侧枝确实改变弯曲与长度。成熟静态比规则控制笼木体更接近参考的局部材质品质。但初始状态仍保留老树皮，构件上下及侧枝端部为接合截口，不能当树梢或根；弯曲区纹理会随网格压缩，尚未证明大幅形变、无缝多段接合或整树成长自然。

源图1536×1024，1118533像素完全透明、454331像素非零透明度，没有alpha255像素。实际浅色背景显示证明本片段未出现明显底板，但其他背景、接合重叠与多构件累计透明效果仍待检验。PNG传输1971771字节，完整图解码约6MiB；只画左格不等于只解码半张图。

## 实际验证

最终采集build/qa/illustrated-fork-2d/2026-11-02T12-17-26.274Z：运行错误0，三状态九个源坐标样本最大误差2.3842×10⁻⁷。1171个动画状态观测中几何/排序CPU p95为2.7ms、绘图记录5.6ms，RAF探针12.5ms。只限该单构件，不是真机、GPU完成时间或整树成本结论。

短片由101个实际Flutter网格状态编码，固定900×1280相机、约10.1秒，画面含时间与姿态进度。10fps是编码速率，不是实时绘制帧率。430×932为浏览器手机视口。

最终静态分析无问题，独立release构建成功，源网格生成、JS语法与实际浏览器流程通过。同一Dart构建对旧简化木体再次采集，旧元数据/着色器分支和源坐标校验通过，结果保存在legacy-regression.json。没有将旧整体视觉失败改成通过，也没有宣称全项目或其他页面测试通过。

复现：Blender --background --python tools/tree_scene/rectification/illustrated_fork_proof.py；独立Flutter build web --release --no-pub --source-maps --target tools/tree_scene/volume_mesh_preview.dart --output build/volume-web；node tools/tree_scene/scripts/capture-volume-2d.mjs --fork。

证据见[局部插画分叉验证/index.html](局部插画分叉验证/index.html)。源图随源码保存，完整网格、逐帧原图与日志另存电脑迁移包/本地备份/验收记录/2026-11-02-局部插画分叉验证。正式lib、web、pubspec、旧母版和小说数据库均未改。

最终复核：六图加载，10.1秒视频在2.5/5/7.5秒可解码，430宽审查页无横向溢出；当前Dart、生成器、网格、元数据及源图哈希均匹配，旧分支结果对应同一Dart构建。evidence-check.json保存结果，代码地图已生成。局部画面改善不代表整树出口通过。

## 下一项的明确出口

先验证两个构件在同一骨架空间中的真实对接：父段末端与子段根部在整个形变过程中共用当前接合坐标，检查树皮接缝、宽度、透明叠层、光向和实际成本；右格不得通过镜像左格来假定光照正确。根颈、幼龄材质、叶冠与枝牌均尚缺资产与整体证据。

只有局部对接与形变成立后才投入新的统一整树，不再依据单片段好看就直接宣布方案可用。任何新整树仍须重新提交四图与连续短片，对照参考审查后才能集成。当前完整目标与A2至A6仍未完成。
