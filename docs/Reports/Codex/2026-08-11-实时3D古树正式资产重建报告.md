# 实时 3D 古树正式资产重建报告

日期：2026-08-11

## 本阶段范围

本阶段只完成批准古树母版的正式 3D 资产重建和机器验收防线，不把资产通过冒充为浏览器 UI 已完成。后续仍需在 Flutter 大纲页真实手机视口中验收镜头、标签、章节/小节枝和动画。

## 已解决问题

- 删除正弦批量树形，改为美术定向的 7 根主枝、28 根次级枝和 84 根末梢枝。
- 成熟树冠使用 4,000 余张小阔叶形成连续冠层，不再是粗枝端点上的稀疏叶团。
- 14 根抓地根代替单一圆盘土壤；碎土为离散几何，不再形成悬浮平台。
- 幼苗、幼树、青年树、成树和古树按枝层错峰生长，不再把成年树整体拉伸或压缩。
- 苔藓限制在根颈，消除形态键变化时漂浮的绿色贴片。
- 正式 GLB 保留骨骼、5 档形态键、4 套动画、16 个主干 marker 和 84 个主枝 marker。

## 自动验证证据

- `flutter test test/presentation/tree_scene_asset_test.dart --plain-name "正式魔树使用批准的古树阔叶美术母版"`：通过。

- Khronos Validator：0 error，19 warning。
- 正式 GLB：5,400,056 bytes；GLB + 7 张 KTX2：8,974,596 bytes。
- 三角形：38,576；节点：147；skin：1；动画：4。

## 仍未关闭的门槛

- 自动视觉校验器已经能拒绝轮廓、背景接缝和移动端主体占比不合格的结果，但最终必须以浏览器真实截图人工复核。
- 当前透明 WebP 是同源静态替身，不能拿透明替身直接代替米白背景浏览器截图做背景边界验收。
- 真实大纲页接入、连续树龄、章节枝与小节枝生长、镜头巡航和左右手势仍属于后续任务。

结论：正式资产结构和标准合规门槛已通过；完整 UI 目标尚未完成，继续推进。
