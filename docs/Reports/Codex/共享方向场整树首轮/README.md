## 实现与失败记录

`continuous-tree-layout.mjs` 定义独立根、主干、六主枝和两段闭合框的当前年龄曲线。主干与侧枝在二维场内并合，冠叶从当前枝段挂点生长，纸面跟随右母枝上的框底。源木质方向场及块面种子只生成一次；整树按当前枝条截面反查源材质域，并在接头混合。

最初尝试将完整成熟木质网格正向缩成独立幼枝，触发幼龄三角翻转。例如年龄 0 的源三角 `(252,152)、(256,152)、(252,156)` 有向二倍面积为 `-0.2159692645729849`。先统一折线源段与目标段仍不足以解决。该正向映射未交付；最终整树使用当前几何场反查，**没有固定 UV 网格和三角朝向通过结论**。`result.json` 中 `fixedUV=false`、`triangles=0`、`minimumArea=null` 明确标示这一区别。局部分叉的固定 UV 结论不能套到整树。

四次静态采集返回的方向场及反查 UV 数值均有限，源木体覆盖 49,964 像素，幼态当前木体覆盖 1,933 像素。当前遮罩来自同一场，但没有正式点击、历史、真机或性能验收。近景放大一张当前年龄实渲缓冲，与运行中换阶段整树图片不同；其模糊仍是必须修复的缺陷。

扩展后已重跑默认与 `--bark` 两个局部入口，六张 PNG 的 SHA256 均与旧归档一致。源码和输出哈希见 `manifest.json`。
