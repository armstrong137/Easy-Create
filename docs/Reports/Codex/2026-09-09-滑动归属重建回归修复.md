# 滑动归属重建回归修复

## 根因

大纲场景构建函数局部变量 dragStartedOnLeft 默认为 true。右侧拖动开始后虽会置 false，但页面重建重新创建局部变量，手势结束可能按左侧章节分发。TreeSceneGestures 本来已保存持久的 owner，页面却没有使用它。

## 修改

删除重复局部状态；拖动更新从控制器 owner 判断是否发送章节 pan；结束时先读取 owner，再调用会清空它的 end。取消后无 owner 不再分发小节动作。

## 验证

- 新增页面级回归：右侧拖动50px后强制重建，继续40px再松手，必须从第3/4节窗口切到第2/3节。修改前失败，修改后通过。
- `flutter test test/presentation/outline_page_test.dart test/presentation/tree_scene_gestures_test.dart --no-pub`：25项通过。
- `flutter build web --no-wasm-dry-run --no-pub`：退出0。
- 浏览器检查创建十章两节，errors=[]，退出0。截图位于 `build/illustrated-outline-check/2026-09-09T10-02-20.714Z/`。

浏览器冒烟没有模拟拖动中强制重建，特定回归由页面测试覆盖。此次没有改变树体美术；镜头缺失、枝干接头及非连续生长仍未解决，不能作为整体视觉通过证据。
