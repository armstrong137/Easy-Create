# 幼树章牌上下文与一体化候选

本轮把上轮独立枝条样件放入幼树上下文。`render-branch-study.mjs` 新增 430×932 上下文截图，按正式页枝牌尺寸和位置组合幼树、新枝条与现有牌框。该截图是独立 HTML 美术样件，不是正式 Flutter 应用截图。

实际看到：新枝走势与原牌框底部不一致；裁开原牌框产生硬断口，新枝根端也露在树干外。此前单独的透明样件检查无法证明它能接入现有牌框，这条拼接组合明确否决。

转为内置 imagegen 编辑完整幼树画面，将章牌、承托枝、树干在同一画面生成，直接保留米白背景，不请求透明图。首次结果的章牌过于靠左，会被 cover 的手机裁切影响；第二次把章牌移入安全区域。

第二张候选已保存：`picture/魔树动画素材/幼树一体化候选/幼树章牌一体化-安全边距.png`。它的接合自然度优于分离样件，作为后续接入候选，不宣称验收通过。原有根部和枝叶也有重绘，不能冒充像素完全不变的图像。

后续接入边界：仅在一个结构节点的幼树阶段试用一体化图；原透明枝牌不能继续叠在这张图上。文字、选中效果、点击热区必须按原图牌面坐标随相同 cover/contain 取景映射；需验证不同屏宽、标题长度，以及下一阶段换图。不能仅用静态截图证明生长动画成功。本轮没有修改正式页面，未调用收费接口。
