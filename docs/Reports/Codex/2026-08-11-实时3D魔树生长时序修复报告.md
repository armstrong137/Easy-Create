# 实时 3D 魔树生长时序修复报告

日期：2026-08-11

## 根因

新增章节或小节时，旧实现启动主树形态键后只等待一个 `requestAnimationFrame` 就启动新枝。首帧往往只完成调度，主树尚未产生肉眼可见的形态变化，因此表现为枝丫先动、主树随后才动。

## 修复

- `TreeGrowthSystem` 公开真实归一化动画进度，并支持等待指定进度。
- 变更播放器等待主树达到 8% 进度后启动新枝；新枝与主树剩余动画并行，不拆成前后两段。
- 成熟树新增小节且结构树龄不变时，不制造虚假的主树等待，只播放小节枝抽生。
- 变更编排从浏览器入口拆为可独立测试的 `MutationPlayer`，避免通过定时猜测验证时序。

## 验证

- 新增红灯测试覆盖“主树可见前新枝不得启动”和“新枝启动后主树尚未结束”。
- `npm test`：26 项全部通过。
- `npm run build`：正式 `assets/tree_scene/dist` 发布包重建成功。

本报告只关闭生长时序缺陷；浏览器移动端构图、标签、交互和批准效果图对照仍需继续验收。
