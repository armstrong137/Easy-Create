# 独立发育整树首轮

幼苗、中龄、成熟使用同一拓扑及固定相机。随树龄增加，主枝改变伸展角度，根颈与粗根独立增宽，框体和纸面共用母枝采样点。浏览器初态无纸牌，成熟两牌。全景、近景、移动视口、101 帧短片及四个区间的 3822 三角形审计均已归档。
