# Flutter二维网格与资产预算验证

本轮把独立连通体的真实顶点、法线、图集UV和三段空间形变绑定导出为二进制数据，在独立Flutter Web入口使用drawVertices绘制，未播放离线树图，也未接入正式应用。整树样件A2仍未通过。

## 实际链路

1. volume_proof.py增加--export和--compact；export_volume_mesh.py输出mesh.bin、mesh.json。二进制使用Float32小端，法线、每顶点三组空间绑定和三角角点UV分别存储。
2. tools/tree_scene/volume_mesh_preview.dart从浏览器读取二进制与固定图集，计算当前枝段、连续顶点形变、法线近似、正交投影及顶点明暗；剔除背面三角形，按深度排序并分批绘制。它不导入正式页面或小说仓库。
3. 单独构建到build/volume-web，capture-volume-2d.mjs只在临时本地端口提供该构建和实验资产，不覆盖build/web。源代码与资产哈希随每次结果保存。

首轮加载遇到Web不支持的NetworkAssetBundle平台接口，已改用浏览器fetch，并对最终代码重建和重跑。冻结候选的源码副本曾被分析器扫描，内容保留并改为.dart.txt文本归档，具名stash未动；不是放宽静态分析规则。最终静态分析无问题，独立Web release构建通过。

测试使用同一Dart构建、Chrome默认GPU、900×1280视口和录像条件，顺序执行，没有并发构建。CPU指标来自Dart Stopwatch；绘图记录不含GPU完成时间，RAF探针也不是实际绘制帧率。不能把16.7ms直接称为真机60帧。827个简化资产动画状态被采集到，完整资产为199个，未用离线3秒渲染时间冒充运行性能。

简化版仍为单一封闭连接体、零非流形边。双向顶点到对侧表面的最大采样距离为0.0028584模型单位，约占片段高度0.073%；这不是严格连续Hausdorff上界，也只检查成熟几何。三个状态中各选三个顶点与Blender数值对照，简化版最大坐标差为2.3842×10⁻⁷；这是九个样本的校验，不冒充逐顶点、所有树龄的完整证明。

## 视觉审查与限制

- 已查看完整/简化实际二维近景、三个状态和430手机视口。干根与分叉体积保留，未见明显简化轮廓损失；固定图集随顶点形变，旧横向断带没有重新出现。
- 二维明暗明显比离线版更暗，当前法线变换、顶点光照与二维地影均为近似，没有完整复现离线面积光、凹凸和接触阴影。材质整体仍未通过。
- 当前按三角中心深度排序，片段基本遮挡可见；整树复杂自遮挡、透明叶簇、木牌、历史镜头与点击尚未验证。
- 本轮只有一个干根片段，无完整树冠或木牌；不叫幼苗/成熟整树，不进入正式集成和千章回归。
- 实验几何资产可减到约0.93MB，但2048图集解码约16MiB，不能仅按PNG传输大小估计手机内存。完整树的资产预算和真机均未验证。

## 复现

生成资产：build/local-render-tools/blender-4.5.9-windows-x64/blender.exe --background --python tools/tree_scene/rectification/volume_proof.py -- --baked --export；增加--compact生成简化版。

构建：flutter build web --release --no-pub --source-maps --target tools/tree_scene/volume_mesh_preview.dart --output build/volume-web。

浏览器：node tools/tree_scene/scripts/capture-volume-2d.mjs；随后node tools/tree_scene/scripts/capture-volume-2d.mjs --compact。

同目录Flutter二维网格验证/index.html保存两份资产结果、三状态、手机截图和简化版全流程录像。录像含加载、静态状态和窗口切换，末段为10秒连续形变，不冒充纯成长片。完整实验资产和日志另存电脑迁移包/本地备份/验收记录/2026-11-01-Flutter二维网格验证；正式lib、旧母版和build/web未改。
