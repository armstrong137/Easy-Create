# 独立发育整树第二轮

沿用首轮相机、木材与开书姿态。主干和母枝加粗，新增五条晚发二级枝和对应叶簇，根增加深度层次，牌框改用与母枝一致的着色。浏览器渲染四张主图、移动视口及 101 帧短片。四个插值区间各检查 6086 个三角形，未发现翻面。

A2 第二轮未通过，淘汰以独立平面条带相互覆盖为主的整树造型。下一方案先验证真正共享截面的根颈、主干和承托枝节点。用同一光向近景检查连接轮廓、木纹连续性和牌底承托，再扩展成整树样件。浏览器移动视口证据与真机验收分开。
