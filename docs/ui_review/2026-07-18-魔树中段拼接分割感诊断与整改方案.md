# 魔树中段拼接"分割感"诊断与整改方案

> 日期：2026-07-18
> 触发：用户视频 video(5).mp4 反馈"树木生长的方式丑陋滑稽，分割感太严重"
> 证据帧：`docs/ui_review/rounds/2026-07-18/tree-tile-artifacts/`（自视频 9.5s / 17s 抽帧）

---

## 一、问题清单（帧级证据）

对视频逐帧检查，"分割感"由四个叠加的视觉缺陷构成：

1. **周期性"鬼影带"**：树干上每隔一个瓦片步长出现一条半透明重影带
   （17s 帧 y≈240-300 / 390-440 / 520-570）。这是瓦片重叠羽化区——
   上瓦片藤蔓经 ShaderMask 渐变叠在下瓦片上，两套**内容错位**的藤蔓
   半透明叠加，观感像"树干上缠了几圈雾"。
2. **硬缝仍在**：羽化只处理了瓦片顶部渐变，瓦片交界处藤蔓编织股
   依然对不上（9.5s 帧 y≈600 有清晰的水平切线，藤股在缝处断开错位）。
3. **镜像对称伪影**：相邻瓦片上下镜像交替，叶子和藤股形成明显的
   镜像对称图案，一眼看出"同一张图翻来翻去"。
4. **树干轮廓节奏断裂**：顶段有锥度、中段恒宽直筒、底段外扩——
   三段宽度不衔接，整棵读作"三种树拼起来的柱子"。

## 二、根因（不是参数问题，是路线问题）

**所选中段素材不是无缝可平铺纹理。** s2/s3_mid 是从整树照片
y∈[650,1150] 直接裁的：上下边界处藤股的位置、角度、粗细各不相同，
任何运行时手段（硬拼 → 硬缝；镜像 → 对称伪影；羽化 → 鬼影）都只能
把不连续换一种方式暴露，不能消除。人眼对植物纹理连续性极其敏感。

回看整条失败链，三次尝试死于同一个物理限制：

| 尝试 | 结果 |
|---|---|
| 整图等比放大 | 泥土超宽冲出屏幕 |
| 整图只放高度 | 纵向拉伸变形（"强拉伸的照片柱子"） |
| 切片平铺（硬拼/镜像/羽化） | 分割感（本次） |

**结论：用一张光栅照片在运行时凑出"任意高度的树干"这条路走不通。**

## 三、整改方案

物理上只剩两条正路，按优先级列出：

### 方案 A（推荐，质量上限最高）：离散高度档 × 完整素材

树高本来就是离散档位（章数 → 档位）。放弃运行时拼接，
**每个高度档配一张完整的树图**，档位切换时整图淡换：

- 素材需求：同风格参天藤 **3~5 张不同高度**（约 1.0x / 1.4x / 1.8x /
  2.2x 屏高比例；同泥土、同画风、藤干自然连续）。用户素材本就来自
  AI 生成渠道，用同一提示词补"更高的树"即可。
- 实现：`treeGrowthFactor` 映射到最近档位；`_layoutWindow` 回到
  "整图 + 镜头平移"（fill 整图零拼接零变形）；档位切换用单次淡换
  （非整树常驻 AnimatedSwitcher，只在换档瞬间过渡）。
- 优点：零拼接、零变形、完全符合"照片级素材直用"红线；
  树高叙事保留（章多→换更高的树+更长的镜头行程）。
- 依赖：需要用户提供/生成新素材（提供提示词参考：与
  `picture/` 现有参天藤同风格、纵横比约 941:2400 / 941:3000 等）。

### 方案 B（无新素材时的立即止血）：整图恒定 + 阶段成长

- `_layoutWindow` 回到"整图 contain、树背景恒定"（此前已验证的
  稳定版本）：泥土贴屏底、零拼接、零变形。
- 成长感由既有三阶段素材（幼苗→缠绕→参天）+ 章带滚动深度表达；
  待方案 A 素材到位后无缝升级成多档位。
- 代价：树不再随章数变高（用户此前不满意这一点，但对比"分割感"
  是两害相权取其轻的过渡态）。

### 不再考虑的路线（已证伪，禁止回头）

- ❌ 整图纵向拉伸（变形）
- ❌ 切片平铺，无论硬拼/镜像/羽化/更大重叠（分割感的根源）
- ❌ 程序化 CustomPainter 画中段藤蔓（违反"禁矢量手画"红线，
  且照片与手绘衔接必然违和）

## 四、建议执行顺序

1. **立即**：按方案 B 止血——回滚中段平铺，恢复整图恒定布局
   （保留既有"先长枝后镜头/固定土壤/无整树鬼影"成果，只动树背景）。
2. **并行**：用户按方案 A 的素材需求生成 3~5 张不同高度参天藤，
   放入 `picture/`。
3. **素材到位后**：实现多档位整图方案，恢复"章多树高"叙事。

## 五、验收标准（方案 B 止血版）

- 任意章数、任意镜头位置：树干上没有任何水平缝、重影带、对称伪影。
- 泥土贴屏底且不随加章移动；新枝先长、镜头后动（沿用既有成果）。
- 全量测试绿；真机录屏无"分割感"。
