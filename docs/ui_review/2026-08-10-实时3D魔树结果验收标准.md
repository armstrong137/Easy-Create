# 实时 3D 魔树结果验收标准

> 定稿日期：2026-08-10
> 原则：只认最终画面、动画录屏、性能数据和可复现命令，不接受“已经实现”“基本接近”或单看代码完成度。

## 一、判定规则

1. 所有标记为“硬门槛”的项目必须通过；任一失败即不得接入生产大纲页。
2. 机器检查只负责客观结构与性能，视觉是否匹配以固定机位截图和用户终验为准。
3. 每次评审必须同时提交参考图、同尺寸结果图和 50% 透明叠图，禁止只提交单张美化截图。
4. 测试必须使用正式手机视口 `430×932 @ DPR 3`，同时补测 `390×844` 和 `360×800`。
5. 降级档不能改变信息架构和树形，只能降低叶片数量、阴影、粒子、纹理和 DPR。

## 二、G0 美术资产包门槛

**硬门槛。**

执行：

```powershell
python scripts/validate_magic_tree_art_package.py --root assets/source/magic_tree --json
python -m unittest scripts.tests.test_validate_magic_tree_art_package -v
```

通过条件：

- `pass: true`，13/13 张正式图片可解码且达到最低分辨率。
- `README.md` 和 `licenses/ASSET_LICENSES.md` 存在且非空。
- 叶片图集为 RGBA；完全透明像素 20%~90%，完全不透明像素 ≥8%，半透明像素 ≤10%。
- 候选图不得替代同名正式母版。

## 三、G1 静态模型门槛

**硬门槛。** 固定正交相机渲染 `age=1.0` 的正视、侧视和背视图。

通过条件：

- 正视轮廓与 `树形正视图.png` 的 silhouette IoU ≥0.88。
- 侧视轮廓与 `树形侧视图.png` 的 silhouette IoU ≥0.82。
- 第一次主分叉高度/树高为 0.28~0.34。
- 冠幅/树高为 0.62~0.78，冠深/冠幅为 0.58~0.68。
- 5~7 根主要枝；根颈至少 7 根可辨识主根，无悬空根和封死的根土接触面。
- 正侧视主干高度差 ≤1%，根部基线误差 ≤画面高度 1%。
- 不得出现仙人掌、藤柱、麻花主干、圣诞树锥体或密实无负空间树冠。

提交证据：三张参考图、三张结果图、三张 50% 透明叠图、GLB Validator 报告和 Blender 源文件。

## 四、G2 五阶段树龄门槛

**硬门槛。** 固定相机渲染 `age=0.08/0.25/0.48/0.72/1.00` 的正视与侧视，共 10 张。

通过条件：

- 每一阶段都是完整树，有根、主干、树冠；不得是成树缩放或从下向上揭开。
- 树高严格单调，树干基点世界坐标漂移 ≤0.2%。
- `age=0.72→1.00` 树高增幅 ≤10%，主要变化是根颈、主干、冠幅和次级枝增厚。
- 第二阶段以后单叶中位尺寸变化 ≤20%，叶片数量随树龄增加。
- 相邻年龄连续播放时，任一骨骼角速度和 Morph 权重导数不得出现单帧跳变。
- 60fps 录屏逐帧检查，无换模型闪烁、几何穿插爆发和纹理突然切换。

## 五、G3 章节目枝动画门槛

**硬门槛。** 分别录制新建章和新建节，并在进度 `0/0.15/0.35/0.60/0.82/1.00` 截图。

通过条件：

- 章枝和节枝使用相同的根颈、锥度、分叉、芽点和叶片生长语言。
- 新枝根点与父级 marker 的世界空间距离始终 ≤父枝半径的 5%。
- 枝条从根到梢连续延伸，禁止横向擦除、贴图平移、伸缩管或整枝缩放。
- 树皮先隆起，枝条后伸长，叶片后展开，枝梢最后形成木质托架和标签。
- 章牌/节签由枝梢分叉直接承托；场景节点中不得存在连接线、绳索、链条、吊环或标签串联。
- 新建章节 950ms 时间轴中，主树必须在新章枝前 120ms 内开始响应，禁止枝丫先动。
- 已有枝条世界挂点在新增章前后误差 ≤0.5%，不得重新均分和整体滑动。

## 六、G4 大纲页 UI 门槛

**硬门槛。** 使用包含 10 章、每章 8 节的数据集测试。

通过条件：

- 章级标签只在屏幕左侧，同时最多 2 个。
- 当前章的小节标签只在屏幕右侧，不得越过中线。
- 左侧章牌和右侧节签都由真实枝条直接承托，不得使用 Flutter 胶囊或屏幕连接线。
- 树、根、土壤和 `#FDF6EC` 环境属于同一渲染场景，无矩形底、抠图边、灰边或色差接缝。
- `430×932`、`390×844`、`360×800` 三个视口均无标签、按钮、树枝重叠。
- 章标题 20 个汉字、节标题 30 个汉字时，牌面使用受控换行/省略，不能撑大布局。

## 七、G5 浏览与树龄解耦门槛

**硬门槛。** 十章小说首次进入停在第十章树底，然后左侧滑动到引子。

通过条件：

- 相机从树底沿预设曲线上移到树冠，不能瞬移、缩放整棵树或淡出换景。
- 切换前后 `structuralAge`、主树骨骼矩阵、Morph 权重、叶片实例数量逐值相同。
- 浏览过程只产生 `focusChapter`，不得产生 `setAge` 或生长 mutation。
- 左侧 pointer down 后锁定 chapter 手势，跨越中线仍不能切换小节。
- 右侧 pointer down 后锁定 section 手势，跨越中线仍不能切换章节。
- 松手后一次连续阻尼吸附到目标，禁止先滑一段、停顿、再补第二段。

提交证据：完整录屏、相机轨迹 JSON、切换前后树状态 JSON diff（必须为空）。

## 八、G6 性能与稳定性门槛

**硬门槛。** 真机测试，不接受桌面浏览器代替。

- 高档设备交互 p95 帧时间 ≤20ms；中档 ≤24ms；低档 ≤33.3ms。
- 新增章节动画不得连续 3 帧超过 50ms。
- 10 章 × 8 节高档 draw call ≤80，三角形 ≤250k，GPU 纹理常驻 ≤96MiB。
- 后台恢复、旋转屏幕和 WebGL context lost 后，树龄、焦点章和标签状态一致，且不重播历史生长动画。
- 连续新增 10 章、每章 8 节后无内存持续增长、无黑屏、无标签丢失。

## 九、G7 用户终验

**最终硬门槛。**

必须向用户展示：

1. 五阶段正侧面对照图。
2. 新建章完整录屏。
3. 新建节完整录屏。
4. 第十章树底滑到引子树冠的完整录屏。
5. 三档设备性能报告。
6. 正式 `430×932` 大纲页截图，与 `章节目枝直接承托效果图.png` 并排展示。

只有用户明确回复通过，才允许删除旧 2D 回退并把 3D 开关设为默认。任何“代码已经完成”或“指标大部分通过”都不能替代用户终验。
