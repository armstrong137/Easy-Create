# 小节工作台空间动效实施计划

目标：遵循用户确认的二维材质与空间动效方向，保留单卡主区、卡包重排和全文写作，逐项完成打开、保存、放回与返回反馈。

架构：继续使用 Flutter 原生控件与现有 Riverpod/SQLite 数据流。导航转场由小节模块共享，静态卡片和正文仍使用现有组件，不引入实时 3D 引擎。

- [ ] 主区与卡包统一打开编辑器：前移、轻微透视展开及正文淡入；返回反向收回；尊重系统减少动画设置。验证：小节交互测试、静态分析、真实浏览器录屏和截图。
- [ ] 卡包展开、排序与放回反馈：保留真实数据操作，补齐空间层次与落定状态。验证：拖放、重排、滚动及数据归属。
- [ ] 编辑器沉浸材质与保存反馈：长文可读、键盘避让、失焦与返回保存可靠。验证：长文、保存、返回及真实页面。
- [ ] 对照统一视觉与性能要求验收，更新进度及代码地图，中文提交并推送。未取得真实画面与动效证据不得标记完成。
