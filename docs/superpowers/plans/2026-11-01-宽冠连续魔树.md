# 宽冠连续魔树实施与验收

用户于2026-11-01确认成熟形态采用后期参考的宽冠古树；空书保持完整小树苗。此决定覆盖早期细长树要求。当前十章后继续向上追加主干的实现只是阶段原型，不能作为最终宽冠方案，也不能仅凭性能和测试通过切换正式默认。

## 成功标准

- 从完整幼苗连续长成宽冠古树。冠幅来自真实主枝、次枝与叶簇，禁止横向拉伸图片、缩放成年树冒充成长或按阶段换图。
- 进入成熟阶段后，高章节数仍保持宽冠构图，不再逐章将主干无限抬高。新增章节进入真实冠层支路，旧节点在追加与历史浏览中不重排。
- 左章右节，最多两章与当前章两节；牌面保持可读，实际木质枝干连接真实母枝。不能用卡片列表或细线替代实体枝牌。
- 历史只改变镜头和可见内容，不回退树龄。树体、母枝遮罩、牌面与热区共用坐标，窗口变化和生长中间帧也不得脱节。
- 手机与宽屏实际浏览器完成全景、近景、历史及牌面点击。逐张检查画面与动效，自动测试不能代替视觉判断。

## 推进顺序

1. 重建基础冠形：保留真实根、主干与幼龄生长机制，调整主枝走向和冠层分布，形成宽阔而有负空间的成年树冠。验证初始、首章、中龄、成熟样图及连续树龄连接；这一阶段不称为高章节数宽冠完成。
2. 用冠层支路替代十章后纵向主干追加：采用稳定的层级地址生成支路，新增只生长新枝，不搬动旧根点；成熟树整体保持限定构图。验证10、30及更高章节数的实际轮廓和节点稳定性。
3. 统一母枝附着数据：章/节牌读取实际母枝位置、当前半径与遮罩，不能继续把所有挂点视为主干弧长。高密度近景不得将文字吞入木质，也不得只靠放大粗主干解决间距。
4. 调整二维镜头与实体牌面布局：依据实际节点与母枝计算近景，保持顺序历史手势、完整可读牌面及最多两章两节；跨度大时优先确保真实连接和可读性。验证跨支路、窗口变化及动画中间帧的实际命中。
5. 做完整浏览器和默认入口验收：新建、历史往返、重命名、小节进入、重新进入已有小说、全景及增长录屏。确认正式默认使用连续几何路径，再运行无实验开关的构建验收。

## 实施约束

- 继续使用现有二维材质与原生几何，不新增其他页面功能，不改小说内容或业务ID。
- 尽量复用已验证的材质生命周期、当前几何复用、可见区域剔除及真实牌面命中机制。
- 旧测试中依赖“全部章节沿一根无限长主干纵向排列”的假设需随新结构更新；真实接合、节点稳定、历史不退龄及点击正确的要求不能降低。
- 性能测量与剖析分开，独立测量避免并发构建干扰。当前成熟阶段约21ms仍需继续处理，但不再以局部性能微调代替宽冠视觉主线。
- 每个完成的改动单元更新进度与代码地图，中文提交并推送；整体目标保持进行中，直到以上结果全部有当前证据。
