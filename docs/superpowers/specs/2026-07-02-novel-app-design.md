# 设计文档：小说家灵感与大纲 App（代号：Create Something）

> 产出方式：brainstorming skill 与用户逐问收敛，三节设计均已获用户确认
> 定稿日期：2026-07-02

## 一、产品定位

小说家专用手机 App（iOS + Android），核心功能 = **小说大纲整理 + 灵感随时记录**。
卡片字数无上限，可直接在 App 内写完整小说。多作品制、纯本地存储、无账号无后端。

## 二、页面结构与交互规格（定稿 v2）

### ① 首页｜创作宇宙
- 暗淡星空背景 + 真实摄影 3D 星球（真实自转角度）
- 左右滑动切换星球 = 切换小说（地球、火星、木星、水星…每球一书），星球质感必须来自真实照片生成的 3D 模型
- 创作能量反馈：
  - 零灵感零大纲：星球**待机微转**（约 2 分钟一圈；2026-07-03 用户反馈静止像故障，由"静止不转"改为微转）、星空最暗淡
  - 灵感越多：自转稍快（肉眼可见但不能太快，有上限）、星光渐亮（不能太亮，有上限；2026-07-03 定稿：四张用户星光背景按创作能量档位递增切换）
- 最近几条灵感以三维轨道环绕星球飞行（不显示全部）：
  - 字体：加粗纯黑楷体；超长省略号截断
  - 星球与字体比例要和谐：星球不能太小、字体不能太大
  - 环绕方式要真实、三维（2.5D 实现：缩放+透明度+星球遮挡）
  - 可读性方案（待终审）：黑字加细白描边
- 顶部 "Create Something"：纯白 Arabic Typesetting 字体；**点击 = 创建新星球（新小说）**
- 点击星球 → 进入该小说的大纲页

### ② 大纲页｜黑白铅笔树
- 纯白背景，屏幕中央一棵**细长的黑白铅笔手绘树**（禁彩色、禁宽版，宽了占屏难看）
- 初始状态（2026-10-31 用户改定）：空书显示完整小树苗，有根、主干和叶簇，沿用较新的整改方案。
- 左右两侧各一个**玻璃质感、动态反光的"＋"号**：
  - 点左＋ → 长出章级枝丫，标注"引子 / 第一章…"
  - 点右＋ → 长出节级枝丫，标注"第一节 / 第二节…"
- 枝丫文字交互：长按 → 编辑 / 删除选项；**双击 → 进入该章/节编辑页**（可修改标题）
- 本形态**替代**早期讨论的左右双栏联动方案（已作废）
- **树的生态成长**（2026-07-02 用户补充定稿）：树有自己的生命历程——
  - 章节少时是**小树**：树干细嫩、枝条稀疏、笔触轻浅，没有年轮与岁月痕迹
  - 章节越建越多，树**成长、变老**：树干变粗变高、枝丫层次变密、
    笔触加深（排线阴影）、逐渐出现年轮质感与结疤等岁月痕迹
  - 树龄由该小说的章节规模驱动（与首页星球创作能量同理，封顶保底）

### ③ 灵感魔毯（全局灵感容器，原"布袋子"）
- 阿拉丁神话飞天魔毯配色；展开 / 缩成一球的动态 3D 质感
- 仅在大纲页出现，驻留右上角，**永远处于最顶层**（展开收起不影响下面的树）
- 点击展开：占据屏幕上部一小部分，**展开大小随灵感数量伸缩（有上下限）**
- 最多显示几条，更多需在展开区域内下滑
- 灵感可拖拽到树上任意章/节；**拖入后魔毯自动缩回小球**

### ④ 小节页｜信用卡卡堆
- 顶部：可编辑的小节标题
- 主区默认只显示**最新一张**灵感卡
- 卡片样式：纯白卡片 + 四周 3D 纯黑细框；大小随文字长短自适应；超长省略
- 下方"卡片包"：点开 → 全部卡片展开（macOS Dock 式），下滑浏览，长按重排序
- 点开单卡可查看/编辑全文，**无字数上限**（须支撑数万字流畅编辑）

### ⑤ 全局灵感速记
- 任何页面：左下角 + 右下角双按钮 = 语音识别输入 / 文字输入
- 默认左 = 语音、右 = 文字；**位置可互换**（照顾左右利手、打字派/语音派）
- 语音识别使用手机系统自带本地引擎（无后端）

## 三、灵感生命周期（用户定稿规则）

```
新灵感 → 进入全局灵感魔毯（所有星球共享可见，按创建时间排序，非修改时间）
拖入某小节 → 从魔毯消失，归属该小节（魔毯缩回小球）
从小节删除卡片 → 放回魔毯（仍按创建时间排序）
在魔毯里删除 → 真正删除，不可恢复
```

## 四、技术选型（已采纳）

**Flutter**（对比 React Native + Three.js 与原生双端后胜出）。决策理由：
1. 本 App 灵魂是大量独创 2D 动画 UI（铅笔树/魔毯/卡堆），Flutter 自绘引擎是最强项
2. 3D 星球收敛为"贴图球体"最简场景：FragmentShader 球面贴图 + NASA 公有领域真实摄影纹理，转速/光照为 uniform 参数，无需完整 3D 引擎
3. speech_to_text 插件直通双端系统本地语音识别
4. 一套代码双平台，对多智能体接力开发最友好

## 五、数据模型（SQLite / drift）

```
novels（星球=小说）:        id, title, planet(贴图标识), sort_order, created_at
chapters（章）:             id, novel_id→novels, title, sort_order
sections（节）:             id, chapter_id→chapters, title, sort_order
inspirations（灵感真身）:   id, content(无上限), created_at, updated_at,
                            section_id(可空: NULL=在魔毯; 非空=挂在该小节),
                            card_order(小节内卡堆顺序)
```

- 灵感生命周期完全由 `section_id` 单字段表达，无冗余状态
- 派生数据（不入库）：星球转速 = f(灵感数+章节数)，星光亮度同理，封顶保底

## 六、模块架构

```
lib/
├── core/          # 主题、常量（转速曲线、魔毯尺寸上下限等）
├── data/          # drift 数据库、仓库实现
├── domain/        # 实体 + 用例（业务规则唯一出口）
├── presentation/
│   ├── home/      # 星空、星球 Shader、环绕灵感轨道、星球 PageView
│   ├── outline/   # 铅笔树 CustomPainter、玻璃＋号、灵感魔毯
│   ├── section/   # 卡堆、卡片包、全文编辑器
│   └── shared/    # 全局双速记按钮、灵感输入弹层
└── main.dart
```

状态管理：Riverpod。

## 七、关键技术攻坚对照

| 界面元素 | 实现技术 |
|---------|---------|
| 真实 3D 星球+变速自转 | FragmentShader 球面贴图 + NASA 纹理，转速/光照 uniform |
| 星空明暗随创作量变化 | 程序化星点绘制，亮度参数化 |
| 环绕灵感文字 | 2.5D 椭圆轨道（缩放+透明度+遮挡），楷体加粗黑字+细白描边（待终审） |
| 铅笔树生长 | CustomPainter 手绘笔触 + 生长补间动画 |
| 玻璃＋号 | BackdropFilter 模糊 + 动态高光 |
| 灵感魔毯 | Rive 交互动画，展开高度=f(灵感数, 有上下限) |
| 卡堆展开 | 自定义 Stack 变换动画（Dock 式） |
| 语音速记 | speech_to_text（双端系统本地引擎） |
