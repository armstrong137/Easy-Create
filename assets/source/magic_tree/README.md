# 实时 3D 魔树美术资产包

## 一、用途

本目录是实时 3D 魔树的正式建模、材质、骨骼和动画母版。目标不是用图片帧播放动画，而是用同一套 Blender 源模型、骨骼、形态键和运行时枝条系统复现母版中的树形与 UI 结果。

正式实现必须逐图对照 `docs/ui_review/2026-08-10-实时3D魔树结果验收标准.md`。机器校验通过只说明资产包完整，不能代替最终画面对照和真机验收。

## 二、正式母版

### 树形与成长

- `references/树形正视图.png`：成熟树正交正视建模基准。
- `references/树形侧视图.png`：成熟树正交侧视建模基准。
- `references/建模母版-成熟树四视图.png`：正、侧、背、三分之四视图的一致性参考。
- `references/五阶段成长分镜.png`：幼苗、幼树、青年树、成树、古树正面成长目标。
- `references/建模母版-五阶段侧视图.png`：五阶段冠深、根深和枝条前后关系目标。

### 枝条与 UI

- `references/章节枝六阶段分镜.png`：章枝与节枝从树皮隆起到枝梢托牌的动画关键姿态。
- `references/章节目枝直接承托效果图.png`：章牌、节签必须由独立木质枝梢直接承托。
- `references/左右分区交互效果图.png`：章只在左侧且最多两个，节只在右侧。
- `references/树龄与浏览解耦对照图.png`：十章大树从第十章切到引子时只移动相机，不改变树龄。

### 材质

- `references/材质母版-PBR细节.png`：树皮、嫩枝、叶片、根土接触、木质牌框和发光裂隙的视觉基准。
- `textures_source/leaf_atlas_rgba.png`：带透明通道的叶片基础图集。
- `textures_source/leaf_atlas_chroma.png`：叶片图集的原始品红底版本，用于重做透明边缘。
- `textures_source/bark_old_basecolor_source.png`：老树皮基础色源图。
- `textures_source/soil_basecolor_source.png`：土壤基础色源图。

树皮和土壤源图不是完整 PBR 套件。法线、粗糙度、AO、高度和发光遮罩必须在 UV 与模型确定后生成和烘焙，禁止把基础色图复制到其他通道冒充材质。

## 三、形态契约

- 成树第一次主分叉位于树高 28%~34%。
- 成树有 5~7 根主要枝，冠幅/树高为 0.62~0.78。
- 树龄是全书结构状态，不能由当前浏览章节反推。
- 每个树龄阶段都是完整树，禁止整体缩放、向上揭开、切片拼接或纵向拉伸。
- 章枝和节枝复用同一套曲线、锥度、分叉、芽点和叶片生成器。
- 每个章牌和节签都由所属枝梢自然分叉直接承托，禁止线、绳、链、吊环和标签串联。
- 章级内容只在左侧且同时最多两个；当前章的小节只在右侧。

## 四、光照与色彩

- 环境底色：`#FDF6EC`。
- 主光：暖色左上方大面积光源。
- 补光：低强度冷色正面/右侧填充。
- 树皮：深胡桃木、赭褐和低饱和苔藓绿。
- 叶片：深橄榄绿，嫩叶略亮，叶背更浅更哑。
- 魔法发光：金绿色细裂隙，覆盖面积不得超过可见树皮的 3%，禁止整棵树描边发光。

## 五、目录边界

- `references/候选-*` 是历史评审过程，不是正式建模输入。
- 无前缀的正式母版和 `建模母版-*`、`材质母版-*` 才参与资产包校验。
- Blender 源文件必须保存到 `blender/magic_tree_master.blend`，不能只交 GLB。
- 最终 GLB、KTX2 和运行时资源另存到 `assets/3d/magic_tree/`，不得覆盖源图。

## 六、机器校验

```powershell
python scripts/validate_magic_tree_art_package.py --root assets/source/magic_tree
python -m unittest scripts.tests.test_validate_magic_tree_art_package -v
```

只有两条命令都返回退出码 `0`，才能进入 Blender 建模。最终模型仍须通过结果验收标准中的全部硬门槛。
